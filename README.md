# OCT E-Portfolio System

Project source snapshot by Lush Cielo A. Valera.

## Contribution

Back-end developer.

## Local setup

Use PHP with PDO MySQL. Import eport_db.sql, set database environment variables listed in .env.example, and serve through Apache/PHP. Create your own local users and academic records.

## Database and configuration

SQL contains the schema only. Set your own environment values and create local test accounts. Production records and user uploads are excluded. The PHP files use environment values; .env.example documents their names.
